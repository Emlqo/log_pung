초기 패키지 설치에서 기본 npm 캐시 경로 쓰기 제한이 있어 작업 폴더 캐시로 해결했습니다. Python SQLAlchemy 선택적 C 확장이 Windows 애플리케이션 제어 정책으로 로드되지 않아 SQLAlchemy 2.0 계열과 `DISABLE_SQLALCHEMY_CEXT_RUNTIME=1`을 사용했습니다. DB/인증 우회가 아닌 선택적 가속기 비활성화입니다. pytest에는 Starlette/AnyIO의 폐기 예정 별칭 경고 1개가 있으나 실패는 없습니다.

| 실제 재부팅/절전 후 재개 | 미검증. 운영 설명서 실제 기기 검증표 수행 |
