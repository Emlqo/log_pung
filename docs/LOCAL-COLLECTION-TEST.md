# 교사 본인 PC에서 수집 → 서버 저장 시험

2026-10-02. 교사가 기존 진단 화면의 로컬 표시를 확인했고 다음 단계로 방문 URL·검색어를 시험 서버까지 전송하는 시험을 요청했습니다. **이번 구현은 교사 본인 PC 전용 별도 시험**입니다. 기존 `dist` 확장과 Google 인증 진단 서버에는 수집 기능/권한을 추가하지 않았습니다. 학교 학생 정책 배포용 수집 프로그램은 아직 아닙니다.

## 지금 실행하는 순서

1. 프로젝트 폴더 `outputs/classroom-pilot`에서 **start-local-collection.cmd를 더블클릭**합니다. 현재 작업 환경에는 Python 개발 환경이 준비되어 있습니다.
2. 열린 콘솔에서 이번 시험에 쓸 비밀번호를 정합니다. 영문·숫자·기호 12자 이상입니다. 입력 글자가 화면에 보이지 않는 것은 정상입니다. 비밀번호는 파일에 저장하지 않고 실행 중 해시로만 사용합니다. 콘솔 창은 열어 둡니다.
3. Chrome에서 `http://127.0.0.1:8765/`를 엽니다. 사용자 이름 `teacher`, 방금 정한 비밀번호로 들어갑니다. 처음에는 서버 저장 0건입니다.
4. `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → **local-test-dist 폴더**를 선택합니다. 기존 `dist`가 아니라 새로 만든 별도 폴더입니다. 기존 진단 확장은 그대로 둘 수 있습니다.
5. 확장 메뉴에서 **교사용 로컬 수집 시험**을 클릭합니다. 안내를 읽고 본인 시험 체크박스를 선택하고 시험 비밀번호를 입력합니다.
6. **인증 후 10분 수집 시작**을 누릅니다. 이 클릭에서만 Chrome 권한 요청이 발생할 수 있습니다. 표시된 권한을 승인하면 교사 시험 인증을 확인한 뒤 수집을 시작합니다. 거부하거나 서버가 꺼져 있거나 비밀번호가 틀리면 시작하지 않습니다.
7. 같은 Chrome 프로필의 일반 탭에서 `https://www.wikipedia.org/` 등을 새로 방문하고, Google이나 Naver에서 `크롬북 수집 시험` 같은 시험용 검색어를 검색합니다. 시작 전 이미 열려 있던 페이지는 새 탐색/새로고침하기 전까지 기록하지 않습니다.
8. 확장 화면에서 방문 URL·검색어와 **서버 수신 확인 N건**을 확인합니다. 교사 웹 화면에서도 같은 항목이 저장되는지 확인합니다. 웹 화면은 5초마다 갱신됩니다.
9. 확장의 **즉시 중지**를 누릅니다. 그 뒤 새 페이지를 방문해도 기록/전송 건수가 늘지 않는지 확인합니다. 최대 10분이 지나면 자동 중지합니다.
10. 교사 웹 화면에서 **시험 기록 전체 삭제·인증 세션 종료**를 누릅니다. 확장의 **중지·로컬 기록 삭제**도 누릅니다. 마지막으로 서버 콘솔에서 Ctrl+C를 누르고 필요하면 시험 확장을 제거합니다.

서버 삭제 후 남아 있던 인증 토큰은 더 이상 유효하지 않습니다. 확장에서 아직 실행 중으로 보이면 다음 요청에 401로 중지하며 직접 중지를 눌러 즉시 끝낼 수도 있습니다.

## 기록 범위

- 직접 시작한 뒤 최대 10분, 최대 200건. 이 Chrome 프로필의 **모든 일반 탭의 새 최상위 탐색**에 적용됩니다. 다른 업무를 동시에 하지 말고 시험용 페이지/검색어로 확인합니다.
- 방문 URL은 원점+경로만 저장하며 일반 쿼리·fragment·URL 자격증명은 제외합니다. 따라서 토큰이 든 일반 URL 쿼리는 보관하지 않습니다. 경로 자체에도 정보가 포함될 수 있으므로 본인 시험용 페이지를 사용합니다.
- 검색어는 Google `.com/.co.kr`의 `/search?q=`, Bing `/search?q=`, Naver `search.naver.com/search.naver?query=`, Daum `search.daum.net/search?q=` 형식만 확인합니다. 다른 사이트의 검색, POST 검색, 주소에 검색어가 없는 검색은 추출하지 못합니다. 모든 검색을 완전하게 기록한다고 주장하지 않습니다.
- 이전 방문기록 API·페이지 내용·제목·쿠키·키 입력·학교 이메일·학생 ID·기기 ID는 읽지 않습니다. iframe과 prerender는 제외합니다. 시크릿 모드에서는 동작하지 않습니다.
- 웹 탐색 이벤트를 사용하므로 백그라운드 탭의 탐색도 포함될 수 있습니다. 기록은 페이지 이동의 증거이며 학생의 집중·실제 열람·미사용을 증명하지 않습니다.

## 인증과 저장

서버는 `127.0.0.1:8765`에만 바인딩합니다. HTTP 예외는 본인 PC의 loopback 시험에만 적용합니다. 공개 인터넷 서버 배포용이 아닙니다. 교사 비밀번호의 기본값·공유 우회 키는 없으며 확장에 비밀번호를 넣지 않습니다. 교사 인증 후 서버가 무작위 10분 bearer token과 시험 실행 ID를 발급합니다. 토큰은 확장의 `storage.session` 메모리에만 보관하고 화면에 표시하지 않습니다. 이것은 학생 Google 인증이나 위변조 불가능한 학교 기기 인증이 아닙니다.

시험 실행 ID와 이벤트 ID는 **이번 시험/중복 전송 방지용 내부 식별값**이며 학생 ID가 아닙니다. 클라이언트가 학교 계정을 확인한 것처럼 만들지 않습니다. 정책 설치된 `admin` 유형에서 이 로컬 확장의 시작을 거부합니다. 별도 수집 앱이 실수로 학교 정책 배포에 사용되지 않도록 기존 게시/서명 도구의 1단계 manifest 검증도 유지합니다.

개발 DB는 workspace의 `work/local-collection.db`에 저장됩니다. 소스 ZIP에는 들어가지 않습니다. 최근 1일 데이터만 조회하고 시작·수신에서 만료 데이터를 정리합니다. 서버/확장 화면에 기록이 따로 있으므로 삭제도 각각 필요합니다. 확장 메모리 데이터는 브라우저 종료·확장 재로드 시 초기화됩니다.

시작 전/인증 실패 시 수집 없음, stop 이후 수집·재전송 없음. 진행 중 요청 1건은 중지 클릭 직전에 이미 서버로 나갔을 수 있습니다. 요청 실패 시 미확인 이벤트만 재전송하고 event ID로 중복 저장을 방지합니다. 재시도 간격은 1→2→4→8분이며 시험 시간이 끝나면 중단합니다. 만료 전에 전송하지 못한 이벤트는 서버에 없을 수 있고, UI의 로컬 건수와 서버 수신 확인 건수가 다르게 표시됩니다.

## 환경을 새 PC에 준비할 때

전달 ZIP에는 `.venv`와 node_modules가 없습니다. 현재 작업 폴더는 이미 준비되어 있지만 새 PC에서는 다음을 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r server/requirements.lock.txt
npm.cmd ci
npm.cmd run build
node scripts/local-test-build.mjs
```

수집 확장 폴더는 `local-test-dist`입니다. 학교 배포용 기존 안전 대기 확장 폴더는 `dist`입니다. `npm.cmd run test:local`로 수집 시험의 자동 테스트를 실행할 수 있습니다.

## 검증의 한계와 실제 배포 전 조건

교사가 실제 Chrome에서 페이지 이동/검색 후 서버 화면에 나타나는 것을 직접 확인해야 합니다. 자동 테스트의 이벤트 mock과 HTTP 시험은 실제 Chrome 수집 성공을 대신하지 않습니다.

이 시험은 **현재 학생 수업 활동 수집 준비가 끝났다는 뜻이 아닙니다.** 학교 관리 기기 식별·등록 조직·사용자 affiliation·정책 강제 설치·비대화형 학생 Google 인증·실제 수업 시간 제한은 여전히 별도 조건입니다. 다음 학생용 단계에는 승인된 수집 범위·수업 시간·시험 학생 2~3명·학교 기기 allowlist·HTTPS 서버와 Google 토큰 검증이 함께 필요합니다. 지금 로컬 시험의 교사 수동 인증을 학생 인증 대신 사용하지 않습니다.
