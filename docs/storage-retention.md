# DB 용량과 7일 보관

## 사용하는 방법

- 사이트 아래 **DB 용량 · 7일 보관 → 용량 확인**: 현재 DB 실제 크기, 7일 이내 활동 건수, 가장 오래된 활동, 마지막 정리 시각을 조회합니다. 자동 조회는 하지 않습니다.
- **기록 검색 → 최근 7일 / 날짜 지정 → 조회**: 한국 시간 기준 시작일·종료일, 학생·검색어·사이트·활동 종류를 DB에서 검색합니다. 100건씩 이전/다음으로 이동합니다. 최신 600건만 검색하던 제한은 제거했습니다.
- 조건만 바꾸면 조회하지 않습니다. 기존 표는 마지막으로 조회한 조건의 결과입니다. 페이지 이동도 명시적인 조회이며 이전 조회 조건을 유지합니다.

## 용량 수치의 의미

운영 PostgreSQL은 `pg_database_size(current_database())`로 실제 DB 크기를 읽습니다. 테이블·인덱스·재사용 가능한 빈 공간이 포함됩니다. 삭제 후 파일 크기가 바로 줄지 않을 수 있으며, 운영 중 강제 VACUUM FULL은 실행하지 않습니다. 로컬 SQLite에서는 페이지 수 × 페이지 크기입니다.

[Neon 공식 2026-10-02 안내](https://neon.com/blog/neon-free-plan-1-gb-per-project)는 Free 프로젝트당 저장 1GB, 월 100 CU-hours입니다. 사이트의 1GB 대비 비율·여유는 **공개 무료 한도와의 단순 비교**입니다. 실제 계정 요금제나 다른 DB/브랜치·프로젝트 전체의 청구 저장량을 조회한 것이 아닙니다. 용량 API는 교사 인증이 필요하며 DB 주소·암호를 반환하지 않습니다.

## 삭제 기준과 실행

활동의 발생 시각(`at`)부터 **7 × 24시간**을 보관합니다. 경계 이후에는 즉시 검색에서 제외합니다. 늦게 전송된 7일 초과 활동도 받아 보존 기간을 연장하지 않습니다. 활동 조회, 학생 상태 확인/전송 등 서버 요청 시 5분에 한 번 이하로 지난 활동·오래된 연결 상태를 자동 삭제합니다. DB 잠금으로 PostgreSQL 동시 정리를 조정합니다. 학생 이름·등록 이메일·반·별칭은 삭제 대상이 아닙니다.

무접속일 정리는 Vercel Cron으로 매일 UTC 19시(한국 시간 다음 날 04시)에 요청하도록 `vercel.json`에 선언했습니다. [Hobby Cron은 하루 한 번이며 정확한 실행 시각은 보장하지 않습니다](https://vercel.com/docs/cron-jobs/usage-and-pricing). 따라서 조회 제외는 7일 경계부터 적용되지만, 무접속 기간의 물리 삭제는 다음 성공한 정기 실행 때 이루어집니다. 스케줄 실패·서비스 중단 시 지연될 수 있습니다. 백업/복구 이력의 보존은 Neon 측 별도 정책입니다.

### 정기 삭제를 켜는 마지막 설정

1. Vercel → `log-pung` → Settings → Environment Variables에서 **CRON_SECRET**을 추가합니다. 준비된 비공개 `retention-cron.env`를 가져오거나 충분히 긴 임의 문자열을 입력합니다. Production에 적용합니다.
2. 저장 후 현재 배포를 **Redeploy**합니다. Vercel이 예약 요청에 `Authorization: Bearer …`를 붙입니다.
3. 사이트 **용량 확인**에 `하루 1회 정기 정리 설정됨`이 표시되는지 확인합니다. 이후 Vercel Cron 실행 기록에서 성공 여부도 확인하세요.

설정이 없으면 정기 삭제 경로는 503, 인증이 틀리면 401로 거부합니다. 일반 접속 시의 자동 정리는 계속 동작합니다. 이 비밀값은 Git, Chrome 확장 프로그램 또는 공개 URL에 넣지 않습니다. 브라우저의 저장된 Vercel 접근 차단 때문에 이번 작업에서 실제 계정 설정은 완료하지 못했습니다.

## 검증

`server/tests/test_retention_storage.py`는 7일 경계, 지연 업로드/조회 제외, 한국 날짜 경계, 600건 제한 없는 페이지 조회, 검색 조건의 DB 적용, 용량 인증·빈 DB, 정기 삭제의 비밀값 검사와 무접속 삭제를 검증합니다. 서버 전체와 프런트 필터 테스트도 실행합니다. 실제 Neon 요금제·사용량은 로그인된 계정 접근 없이는 검증할 수 없습니다. 이미 이전 24시간 정책으로 삭제된 기록은 복원하지 않습니다.
