# 기록의 이메일에 학생 이름 연결하기

교사용 사이트에 로그인하고 아래쪽 **학생 이름 연결**을 펼친 뒤 Google 관리자에서 내보낸 CSV를 선택하고 **명단 연결**을 누릅니다. 한 번 등록하면 서버 DB에 저장되어 다음 접속에도 적용됩니다. 확장 프로그램 업데이트는 필요하지 않습니다.

필수 열은 `First Name [Required]`, `Last Name [Required]`, `Email Address [Required]`입니다. UTF-8(BOM 포함 가능) 또는 CP949, 최대 2MB·10,000행을 지원합니다. 다른 열은 저장하지 않습니다. 한글 이름은 성+이름 순서로 표시하며 이메일의 앞뒤 공백과 대소문자를 정규화합니다. 서로 다른 이름이 같은 이메일에 연결되면 파일 전체를 거부하여 부분 반영을 방지합니다.

- 연결 상태나 활동 기록에 이미 나타난 이메일에만 이름을 붙입니다. CSV만 등록된 사람은 학생 목록·필터·조회 인원에 추가되지 않습니다.
- 매칭되지 않은 이메일은 기존처럼 이메일만 표시합니다. 같은 이름을 가진 학생도 이메일로 구분합니다.
- 이름은 조회 시 연결하므로 기존 기록에도 적용됩니다. CSV를 다시 등록하면 해당 이메일의 이름을 갱신합니다. 이번 CSV에 없는 기존 매칭은 유지됩니다.
- 이름 검색은 화면에 불러온 최근 24시간·최신 600건에 적용됩니다. 이름 매칭은 학생 이메일의 진위를 인증하는 기능이 아닙니다.

명단은 학교 식별값과 이메일을 키로 하는 PostgreSQL `student_directory` 테이블에 저장합니다. 로컬 시험은 SQLite도 지원합니다. 이름 매핑은 활동 기록의 24시간 만료와 별도로 유지됩니다. 원본 CSV는 서버 파일로 저장하지 않고 성·이름으로 만든 표시 이름과 이메일만 저장합니다. 등록 API는 교사 인증과 동일 출처 검사를 적용하고, 조회 API는 실제 기록에 대응하는 이름만 반환합니다. 학생용 API에서는 명단이나 이름을 반환하지 않습니다.

원본 CSV와 DB를 GitHub에 커밋하지 마세요. CSV는 Git·Vercel 및 소스 ZIP 생성 대상에서 제외합니다. 운영 DB의 이름 등록에는 기존 교사 로그인이 필요하며, 웹사이트 배포만으로 로컬 CSV가 자동 전송되지는 않습니다.


## 이메일별 별칭

기록 목록 또는 학생 연결 상태에서 **별칭 수정**을 눌러 학년·반·번호 등을 입력하고 저장합니다. 이름·별칭·이메일이 함께 표시되고, 학생 필터와 내용 검색에도 반영됩니다. 최대 80자이며 빈칸으로 저장하면 별칭만 삭제됩니다. CSV의 이름과 구글 계정 이름은 바뀌지 않습니다.

별칭은 교사 인증을 거쳐 `student_alias` 테이블에 학교 식별값·이메일별로 저장됩니다. CSV를 다시 등록하거나 서버를 재시작해도 유지됩니다. 별칭만 등록한 이메일이 학생 목록에 새로 나타나지는 않습니다. 기존 DB에는 새 테이블만 추가하며 원래 명단을 변경하지 않습니다. 학생 확장 프로그램 배포는 필요하지 않습니다.
