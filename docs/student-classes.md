# 반별 학생

1. 교사 로그인 후 **반별 학생 → 명렬표 올리기**에서 학년도를 확인하고 XLSX를 연결합니다.
2. 이름이 아직 표시되지 않으면 **학생 이름 연결**에서 Google 관리자 CSV를 먼저 연결합니다.
3. **! 확인 필요 → 반 지정**에서 학년과 반을 입력합니다. **번호는 비워도 저장됩니다.**
4. 늦게 연결된 학생은 **명단 새로고침**으로 불러옵니다. 학생 이름을 누르면 **기록 검색** 탭에서 그 이메일로 조회합니다.

명렬표만 있는 학생은 화면에 추가하지 않습니다. 서버가 상태 또는 활동 요청을 수락한 이메일만 등록 학생으로 보관합니다. 이름은 원래 이름 가나다순이며 별칭도 함께 표시합니다. 별칭은 자동 반 배정의 이름 비교에 사용하지 않습니다.

## 자동·수동 배정

- XLSX의 `학년`, `반`, `번호`, `성명` 열을 읽습니다. 중간의 반복 머리글을 허용합니다. `특이사항` 등의 다른 열은 저장하지 않습니다.
- 이메일-이름 CSV 전체와 선택 학년도의 명렬표 양쪽에서 이름이 유일할 때만 자동 배정합니다. 아직 연결되지 않은 동명이인도 중복 판단에 포함합니다. 공백과 유니코드 정규형만 정리하며 비슷한 이름을 추측하지 않습니다.
- 이름 없음, 명렬표에 없음, 동명이인, 수동 배정 번호와 충돌한 학생은 `! 확인 필요`로 표시합니다.
- 수동 반 배정은 학교·학년도·이메일별로 저장합니다. 번호는 선택이며 같은 반에 번호 미지정 학생이 여러 명 있어도 됩니다. 수동 번호 중복은 거부합니다. 자동 배정된 번호를 다른 학생에게 수동 지정하면 기존 자동 배정 학생은 확인 필요로 전환합니다.
- 수동 지정한 반은 새로고침·명렬표 재업로드·별칭 변경·이름 CSV 재등록 후에도 유지합니다. **자동 배정으로 되돌리기**를 누른 경우에만 수동 지정을 해제합니다.
- XLSX 재업로드는 해당 학년도에서 **파일에 포함된 학년의 명렬표 전체**를 교체합니다. 다른 학년과 수동 지정은 유지합니다. 부분 반 파일로 같은 학년을 교체하면 빠진 반의 자동 배정은 해제될 수 있으므로 해당 학년 전체 파일을 올리세요.
- 새 학년도에는 새 명렬표를 올리고 필요한 수동 배정을 다시 합니다. 이메일 등록 목록과 별칭은 학년도와 무관하게 유지합니다.

## 기록 보존과 등록 목록

방문·검색 기록의 기존 24시간 조회/보존 규칙은 그대로입니다. 새 `known_student` 테이블의 이메일·최초/마지막 연결 시각은 최근 기록이 사라져도 유지합니다. 목록에 남아 있다는 사실은 현재 기기 사용이나 접속을 의미하지 않습니다.

최초 배포 시 남아 있는 상태 기록 및 학교를 확인할 수 있는 현재 세션 활동에서 등록 목록을 복원합니다. **배포 전에 이미 삭제된 기록의 학생은 복구할 수 없으며, 다시 연결되면 등록됩니다.** 학생 이메일 자체는 기존과 같이 클라이언트가 보낸 미인증 정보입니다.

## 운영·개발

교사 인증을 적용한 `/api/teacher/roster`, `/api/teacher/classes`, `/api/teacher/class-assignment`만 명렬표·반 정보를 다룹니다. 기존 PostgreSQL에 추가 테이블을 생성하며 기존 테이블을 지우거나 확장 프로그램을 변경하지 않습니다. 로컬 테스트는 SQLite로 실행합니다.

명렬표는 2MB, 총 10,000행, 시트당 100열, 압축 해제 합계 20MB로 제한합니다. 매크로 파일은 거부하고 defusedxml로 XML 파싱을 보호합니다. 업로드 전체를 검증한 다음 DB 트랜잭션으로 저장하므로 잘못된 파일이 기존 명렬표를 부분 교체하지 않습니다. 원본 XLSX/CSV는 저장하거나 Git/Vercel 배포에 포함하지 않습니다. 실제 학생 파일은 로그인한 교사용 화면에서만 올리세요.

자동 테스트:

```powershell
$env:DISABLE_SQLALCHEMY_CEXT_RUNTIME='1'
$testBase = Join-Path $env:TEMP ('classroom-tests-' + [guid]::NewGuid().ToString('N'))
.venv/Scripts/python.exe -m pytest server/tests -q -p no:cacheprovider --basetemp $testBase
node --test server/tests/dashboard-filters.test.mjs
```

테스트에는 가상 이름·이메일만 사용합니다. 실제 PostgreSQL의 교사 업로드와 학교 크롬북 동작은 이 로컬 테스트에 포함되지 않습니다.
